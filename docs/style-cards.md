# 风格卡

画面 = **骨架** + **风格卡**。

- **骨架**全片固定：连续变形、钻进论文（实体纸 + 推进 + 荧光笔）、大画布运镜、章节转场时机、安全区（顶部 64px 进度条、右下角头像）、运动模糊参数。
- **风格卡**只管外观：色板、字体、材质、标志动作、固定元素（进度条 / 字幕 / 头像底座）的样式。

换风格只换卡，不动骨架。一支片子只用一张卡，系列内保持同一张卡。

每张卡都有一份 13.6 秒的参考实现，内容是同一段 Harness² 钩子，放在 `templates/style-cards/`。每个 html 都暴露 `window.seek(t)`（t 的纯函数），可以直接用浏览器打开看，也可以用 Playwright 逐帧渲染。完整参数（色板、字号、缓动、优缺点）见 [`templates/style-cards/style-tests-2026-10-21.md`](../templates/style-cards/style-tests-2026-10-21.md)。

## 卡 ④ 要点

- 色板：纸 `#FFF1E5`、墨 `#33302E`、FT 酒红 `#990F3D`（改进后 / 关键数字 / 我们的标注）、牛津蓝 `#0F5499`（基线）、青 `#0D7680`（✓、连线）、灰 `#B9AFA6`（被拒）、麦色面板 `#F2DFCE`
- 字体：标题 Noto Serif CJK SC Black（钩子 132px / 章节 92px）、正文 Noto Sans CJK SC、数字 Inter 800 + tnum
- 标志动作：标题逐行遮罩上推、导语从左擦出、细线长出、折线从左画到右并同步滚动数字、酒红下划线扫出。不弹跳、不发光
- 章节转场：整页横滑翻报纸（0.6s）
- 固定元素：进度条做成报纸栏目导航（01 导读 … 08 启示），字幕是麦色下三分之一条

## 换卡时的通用规则

- 论文 PDF 一律画成白纸实体页。深色卡（①⑤）要把页面亮度压到约 90% 并加暗角
- 论文原文上划重点统一用黄色荧光笔 `rgba(250,199,117,0.7)`，我们自己画的标注用卡的强调色，让观众分清原文和解读
- 颜色语义固定：改进后 = 卡的强调色，基线 = 卡的冷色，被拒 = 灰
- 风格样片里的表格行、冲突数等数据都是示意，**不能带进正片**
